Политика конфиденциальности приложения FamilyBudget

Разработчик: Титов Аким Андреевич (физическое лицо)

Версия документа: 1.0

Дата публикации: 04.10.2026

1. Область применения

Настоящая Политика конфиденциальности регулирует порядок обработки персональных данных пользователей мобильного приложения Семейный бюджет (FamilyBudget) (далее — «Приложение»).

2. Сбор и обработка данных

Приложение FamilyBudget не собирает персональные данные пользователей.

3. Хранение данных

Пользовательские данные (транзакции, счета, категории, настройки) хранятся исключительно на устройстве пользователя в локальной базе данных. Передача данных на внешние серверы, в облачные хранилища или третьим лицам не осуществляется.

4. Использование данных

Данные, созданные пользователем в Приложении, используются только для функционирования функционала приложения на устройстве пользователя.

5. Аналитика и реклама

В приложении не используются средства сбора аналитических данных (в т. ч. Яндекс Метрика, Firebase Analytics, AppMetrica и др.) и рекламные модули.

6. Разрешения

Приложение не запрашивает специальные разрешения операционной системы (доступ к камере, контактам, геолокации, файловой системе и т. п.).

7. Безопасность данных

Обеспечение безопасности данных осуществляется на уровне устройства пользователя. Разработчик не имеет доступа к данным, хранящимся на устройстве.

8. Изменения в Политике конфиденциальности

Разработчик вправе вносить изменения в настоящую Политику. Актуальная версия размещается по адресу: https://familybudget-privacy.github.io/

9. Обратная связь

По вопросам, связанным с обработкой персональных данных, пользователи могут обращаться по электронной почте: vas_pisar@mail.ru либо akimtitov@vk.com.
